# Світло в Черкасах

Мапа Черкас, на якій видно, де зараз є світло, а де відключення за графіком погодинних відключень (ГПВ) АТ «Черкасиобленерго». Зони світяться зеленим, коли світло є, і сірі під час відключення. Можна подивитися графік на завтра, знайти свою адресу і перемкнутися між режимами «Зони» та «Будинки».

## Як це працює

- **Сайт** — звичайні статичні файли на GitHub Pages: `index.html`, дані мапи `mapdata.json`, зони `zones.json` і графік `schedule.json`.
- **Графік** оновлює GitHub Actions (`.github/workflows/update-schedule.yml`): кожні 10 хвилин скрипт `scripts/update_schedule.py` читає публічний канал [@pat_cherkasyoblenergo](https://t.me/s/pat_cherkasyoblenergo), бере пости з графіками ГПВ і, якщо щось змінилося, комітить новий `schedule.json`. Відкриті сторінки підтягують новий графік самі протягом кількох хвилин.
- Пост приймається, лише якщо в ньому є всі 12 підчерг (1.1–6.2) з коректними годинами. Неповні чи дивні пости ігноруються, і на сайті лишається попередній графік.

## Звідки взялися зони

Адреси для кожної підчерги взято з офіційних PDF «Перелік основних відключаємих споживачів» (графік з 1 жовтня 2026 по 1 квітня 2027). У Черкасах міські адреси є лише в підчергах Х.1. Адреси зіставлено з будинками OpenStreetMap; будинки без адреси в списку отримують підчергу найближчих адрес, тож межі зон приблизні. Точну чергу своєї адреси перевіряйте на [cherkasyoblenergo.com/off](https://www.cherkasyoblenergo.com/off) або в боті [@Cherkasyoblenergo_bot](https://t.me/Cherkasyoblenergo_bot).

## Ручне виправлення графіка

Відкрийте `schedule.json` на GitHub, натисніть олівець і змініть або додайте день у форматі:

```json
"2026-10-22": {"text": "1.1 06:00 - 08:00, 12:00 - 14:00\n1.2 ...\n...\n6.2 ...", "post": null, "at": "2026-10-22T09:00:00Z", "manual": true}
```

`text` — 12 рядків, час у рядку означає години без світла; для підчерги без відключень пишіть `1.1 без відключень`. Запис з `"manual": true` автоматика перезапише лише постом, опублікованим пізніше за `at`.
